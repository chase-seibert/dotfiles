# Common Transcript Errors

Use this local glossary whenever interpreting speech-transcribed text, including
raw user prompts as well as transcript-derived notes and summaries. Treat the
left side as likely transcription noise and normalize it to the right side when
the surrounding context fits. Apply the intended meaning before searching or
acting, even when the user has not manually corrected the transcript first.
